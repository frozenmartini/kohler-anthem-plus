# Icon workbench — every variant, preserved

The complete design history of the integration's icon: 28 numbered SVG variants
(v1 = the hub web UI's original `InterfaceIcon.svg`, through the filled-bar
exploration that produced the shipped v27), plus `icon-workbench.html`, the
self-contained viewer they were compared in — open it in any browser.

These are kept in the repo because it is the project's only backed-up store; the
working copies lived in a scratch workspace outside version control. Nothing
here is read at runtime. To ship any variant: copy it up to `../icon-<name>.svg`
and run `../build.sh <name>` — see `../../README.md` for the design record and
the contrast discipline a candidate should be checked against.

Shipped marks, in order: `icon-bleed-right` (pre-numbering) → v18 (pink,
2026-08-21) → v22 (flat violet, hours on 2026-08-22) → **v27 (violet
three-tone, current)**.
