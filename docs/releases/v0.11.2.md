`Cloud Connection` is no longer hidden by default.

It was created **enabled but hidden** from 0.2.7: it has to keep running whether or not
anyone is looking — its whole value is the record it builds while nobody is watching, and a
disabled entity builds none — so hiding it seemed like the way to keep it out of the way
without switching it off.

That was the wrong trade. Hiding an entity puts **"(Hidden)"** beside its name everywhere it
appears, which reads as a broken entity rather than a deliberate default. And the one moment
this sensor matters — the valve has dropped off Kohler's cloud, the app says it is offline,
and every other entity has silently frozen — is exactly the moment nobody wants to go find
something to unhide first.

It is a connectivity sensor, so it shows as a plain Connected/Disconnected row and costs
nothing while it says Connected.

⚠️ **Visibility applies only when an entity is first created**, so an installation that
already has this hidden stays hidden. Open the Anthem Valve device, show hidden entities, and
clear the hidden flag — or delete the entity and let it be recreated.

Nothing else changed: same unique id, same history, same push-driven checks.
