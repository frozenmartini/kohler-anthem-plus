**Fixed — the Cloud Connection sensor never ran a check of its own.** Both of its triggers (a
60-second controller/valve contradiction, and three hours of valve silence) were dead in v0.2.6:
their timers ran off the event loop and raised, so the three-hour timer never re-armed. Every
answer came from a REST read something else was already making — which is exactly what does
*not* happen during the overnight outage the sensor exists to catch. Confirmed fixed over 48.8 h
live: **13** three-hour checks against **0** ever before, and no gap in the entity's state over
**3.00 h** — the longest before the fix was **11.74 h**.

**Changed — Cloud Connection is hidden by default.** Hidden, not disabled: it keeps running and
keeps its history. New installs only; an existing install keeps it visible, so clear the flag by
hand on the Anthem Valve device if you want it gone.

**Docs — music needs Kohler's K-30319 amplifier**, it is not built into the controller.

**Upgrading:** update through HACS and restart Home Assistant. No config changes, no entities
renamed or removed.
