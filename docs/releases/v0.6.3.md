**Fixed — the Flow number showed a value nobody chose.** On an idle valve it echoed the
valve's flow byte, which is not the flow setting. Two Anthem valves were reporting 24.5 %
and 26.5 % while the owner's panel held **100 %** on both.

**This reverses 0.6.2, which was wrong.** That release relaxed the `flow_is_live` gate after
observing that those idle bytes were perfectly stable — byte-identical across diagnostics
taken 2 h 23 m apart — and reading stability as evidence they were the stored per-zone
setting. They were not. They were junk that happens to hold still, which is more convincing
than the transient junk the capture corpus documents, not less, and that is precisely why it
was mistaken for a setting. One panel reading settled it.

**What the entity does now.** While water is running the valve's own byte is authoritative
and is shown directly, including a change made on the wall panel mid-shower. While the
shower is off it shows **the last flow Home Assistant wrote**, falling back to 100 % — which
is what the valve is sent when a command specifies no flow, so the displayed value and the
commanded value agree. The valve's raw byte is still published as a `reported_flow_percent`
attribute, so the behaviour stays observable rather than merely asserted.

`flow_is_live` says which of the two you are looking at, and is a gate again rather than a
hint: while it is False the valve's byte means nothing, however steady it looks.

**Docs — the reversal is written down rather than quietly undone.** `docs/architecture.md`
now contrasts both installs and states plainly that stability is not meaning, with the
0.6.2 error named. The same reasoning is on `GcsState.flow_is_live` and the entity itself,
so the next person to notice a suspiciously steady idle byte does not repeat the inference.

**Unchanged.** Everything else from 0.6.2 stands: the flow bounds published on the entity,
the `flow_control_available` flag, and the warm-up entity's `mode_never_reported`. No
entities are renamed or removed.

**Upgrading:** update through HACS and restart Home Assistant. Your Flow numbers will read
100 % on an idle valve instead of the valve's idle byte. No config changes.
