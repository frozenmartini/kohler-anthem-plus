A diagnostics change only — no behaviour changes, no new entities. It exists to answer one
question before the firmware entities are redesigned.

## Diagnostics now report every firmware, not just the interface

The Konnect app shows **three different firmware versions** for one system: the touchscreen
interface (2.2), the valves (10), and the gateway (00.74). This integration has a single
`Firmware` entity, which reads whichever version it finds first — so the numbers never lined
up with the app, and on one of the owner's two valves it was reporting the wrong thing
entirely.

That valve's `otaReportedProperties` block describes **Assets** — the artwork bundle — with no
Application block anywhere in its record, so `Firmware` showed `2.00` (the artwork version)
where the app showed 2.2. Its sibling valve, which does have an Application block, was correct
at 2.20. The entity was not wrong to prefer Application; there was simply nothing else to
find, and it fell back to a number that answers a different question.

The valve and gateway versions were invisible in every report, because they live in blocks
diagnostics names but does not reproduce (`configuration`, `iot`, `applicationSource`) — those
also describe someone's plumbing and cloud addressing, which this module redacts everywhere
else.

So reports now carry a `version_fields` map: every version-shaped field in the record, by
dotted path, and **nothing else from those blocks**. Values are taken by key name rather than
by shape, since a version may be a string (`"2.20"`), an int (`10`) or a float; type and
update-bookkeeping labels beside a version (`firmwareType`, `isSingleFirmwareUpdate`) are
excluded by name, so a genuinely new version key is never silently dropped. Anything longer
than a version could plausibly be — a device id, a serial, a connection string — is reported
as its type and length instead of its content.

**Next:** with those paths known, the single `Firmware` entity can be split into the three the
app actually shows, each honest about its own source and reading `unknown` rather than
borrowing another's number.
